Virtual IoT devices — what VEIL6 sees

Each device keeps rotating its IPv6 temporary address (RFC 8981). An outside observer sees many unrelated addresses; VEIL6 links them to one keyed pseudonymous session (HMAC of the NDP binding), so per-device detection still works — and no raw identifier is stored.
